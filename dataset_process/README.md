# Dataset Preparation Pipeline

This folder contains scripts to prepare all training and evaluation datasets for MATCHA. The pipeline has three stages that must be run in order.

## Manual Downloads

Most datasets are downloaded automatically from HuggingFace. The following require manual setup:

| Dataset | Source | Expected Path |
|---------|--------|---------------|
| COCO Captions (training) | [COCO 2017 Annotations](https://cocodataset.org/#download) | `/mnt/lustre/datasets/coco/annotations/captions_train2017.json` and `captions_val2017.json` |
| ParaNMT-5M | [ParaNMT](https://www.cs.cmu.edu/~jwieting/) | `../data/paranmt/para-nmt-5m-processed.txt` |
| NEWTS | [NEWTS Dataset](https://github.com/ali-bahrainian/NEWTS) | `../data/NEWTS/NEWTS_train_2400.csv` and `NEWTS_test_600.csv` |

## Pipeline Overview

```
Step 1: prepare_eval_datasets.py    -->  pkl files (NLI-style eval datasets)
Step 2: prepare_train_datasets.py   -->  per-dataset Parquet files
Step 3: prepare_train_mixed.py      -->  mixed.parquet + index_by_source.json
```

## Step 1: Prepare Evaluation Datasets (pkl files)

Downloads and processes NLI-style datasets into `(premise, correct_answer, incorrect_answer)` triplets saved as pickle files. These pkl files are also used as input by Step 2 for the NLI training datasets.

**Datasets:** snli, multi_nli, vitaminc, mednli, truthfulqa, coco-caption, newts

| Dataset | HuggingFace Source | Type |
|---------|-------------------|------|
| SNLI | `stanfordnlp/snli` | NLI (entailment/contradiction) |
| MultiNLI | `nyu-mll/multi_nli` | NLI (entailment/contradiction) |
| VitaminC | `tals/vitaminc` | Fact verification (supports/refutes) |
| MedNLI | `presencesw/mednli` | Clinical NLI |
| TruthfulQA | `truthful_qa` (generation) | QA truthfulness |
| COCO-Caption | `lmms-lab/COCO-Caption` | Image captions (1k sample) |
| NEWTS | Local CSV files | News summarization |

```bash
cd dataset_process

# Process all evaluation datasets
python prepare_eval_datasets.py --data_path ../data

# Or process specific ones
python prepare_eval_datasets.py --datasets snli vitaminc --data_path ../data
```

**Output:** `../data/{dataset}.pkl` for each dataset.

## Step 2: Prepare Training Datasets (Parquet files)

Converts all datasets from `configs/mixed.json` into Parquet files for efficient streaming during training. For pair-only datasets, incorrect answers are generated by random sampling within each batch.

**Datasets:** All 15 datasets listed in `configs/mixed.json`

| Dataset | HuggingFace Source | Type |
|---------|-------------------|------|
| WikiAnswers | `sentence-transformers/wikianswers-duplicates` | Duplicate questions |
| Quora (QQP) | `sentence-transformers/quora-duplicates` | Duplicate questions |
| AltLex | `sentence-transformers/altlex` | Lexical simplification |
| Simple-Wiki | `sentence-transformers/simple-wiki` | Text simplification |
| WikiHow | `sentence-transformers/wikihow` | Article summarization |
| STS-B English | `PhilipMay/stsb_multi_mt` | Semantic similarity (scored) |
| COCO-Captions | Local JSON annotations | Image caption pairs |
| Flickr30k | `nlphuji/flickr30k` | Image caption pairs |
| SNLI | From Step 1 pkl | NLI triplets |
| MultiNLI | From Step 1 pkl | NLI triplets |
| MNLI Mismatched | From Step 1 pkl | NLI triplets |
| VitaminC | From Step 1 pkl | Fact verification |
| Climate-FEVER | From Step 1 pkl | Climate fact verification |
| NEWTS | From Step 1 pkl | News summarization |
| ParaNMT | Local TSV file | Paraphrase pairs |

```bash
# Process all training datasets
python prepare_train_datasets.py --data_path ../data

# Or process specific ones
python prepare_train_datasets.py --datasets snli quora wikianswers --data_path ../data

# Custom batch size for memory-constrained environments
python prepare_train_datasets.py --batch_size 100000 --data_path ../data
```

**Output:** `../data/{dataset}/{dataset}_train.parquet` (and other splits) for each dataset.

## Step 3: Create Mixed Training Set

Samples up to N rows from each dataset's train split, combines them into a single Parquet file, and builds a source index for interleaved/curriculum training.

```bash
# Mix all datasets (100k samples each, default)
python prepare_train_mixed.py --data_path ../data --config ../configs/mixed.json

# Custom sample size
python prepare_train_mixed.py --sample_size 100000 --data_path ../data

# Custom output directory
python prepare_train_mixed.py --output_dir ../data/mixed --data_path ../data
```

**Output:**
- `mixed.parquet` — combined training data with `source_dataset` column
- `index_by_source.json` — maps each dataset name to row indices for interleaved batch sampling

## Quick Start (run everything)

```bash
cd dataset_process

# 1. Prepare eval/NLI pkl files
python prepare_eval_datasets.py --data_path ../data

# 2. Convert all datasets to Parquet
python prepare_train_datasets.py --data_path ../data

# 3. Create mixed training set
python prepare_train_mixed.py --data_path ../data --config ../configs/mixed.json
```

## Output Format

All datasets are converted to a unified triplet format:

| Column | Description |
|--------|-------------|
| `premise` | The reference text |
| `correct_answer` | A text semantically related to the premise |
| `incorrect_answer` | A text not related to the premise (contrastive negative) |
| `source_dataset` | (mixed.parquet only) Name of the source dataset |
